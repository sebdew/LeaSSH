|---|---|---|
| [0001](0001-authentification-sso-et-compte-local.md) | Authentification : SSO obligatoire, compte local de première connexion | accepté |
| [0002](0002-binaire-unique-front-et-back.md) | Binaire unique, front et back non séparés | accepté |
| [0003](0003-choix-de-la-stack-go-sqlite.md) | Stack : Go et SQLite (tient lieu de `0001-choix-de-la-stack.md`) | accepté |
| [0004](0004-chaine-integrite-du-journal.md) | Chaîne d'intégrité du journal | accepté |
| [0005](0005-synthese-ia-configurable-en-base.md) | Synthèse IA du rapport d'audit configurable en base | accepté |
