# Spécifications par fonctionnalité

Constitution, principe 8 : chaque fonctionnalité a une spécification (`spec.md`), un plan technique (`plan.md`) et des tâches (`tasks.md`). Les trois ci-dessous sont écrites **a posteriori** (ticket #11, DOC-03) pour des fonctions livrées avant la mise en place du cadre ; elles décrivent l'existant et renvoient vers `docs/SPEC.md` pour le détail. Toute nouvelle fonctionnalité crée son dossier **avant** le code.

| Dossier | Fonctionnalité |
|---|---|
| [`sso/`](sso/spec.md) | Connexion unique OpenID Connect |
| [`rapport-audit/`](rapport-audit/spec.md) | Rapport d'audit ISO 27001 / HDS |
| [`provisioning/`](provisioning/spec.md) | Synchronisation des serveurs depuis un bastion |
